Formulas

Theory Marks and Lab Marks

1. Writing a formula

Choose Column type → Formula and type it like Excel. A formula starts with = (maximum 300 characters) and is calculated for every student from that student's own row.

WayExampleMeaning
By name[Lab 1]The column named Lab 1 (capital letters do not matter). Follows the column when it is renamed or moved.
By letterC5The column with the letter C. A = Reg No, B = Name, C = first column, D = second ... The row number is ignored.
Range of lettersC5:H5All columns from C to H.
  • Operators: + - * / ^ % (50% means 0.5) and brackets ( ).
  • Comparisons: = <> < > <= >=. Text goes inside quotes: "Pass".
  • AB (absent) is ignored like an empty cell: SUM and AVERAGE skip it, and in + - * / it counts as 0.
  • A formula can use another formula column, but not its own column.
  • Conditions in COUNTIF, SUMIF and AVERAGEIF are written in quotes: ">=10", "<5", "<>0", or just a number such as 18.

9. Excel download

The downloaded Excel file keeps the formulas as real Excel formulas. BEST, BESTAVG, PERCENT and BETWEEN are written out with normal Excel functions. IFS and CONCAT need Excel 2019 or newer.

10. If a formula shows Err or is refused

  • Err in the table: dividing by zero, a [Name] that no longer exists, a letter that no longer points to the column you meant (after deleting a column), a number out of range (for example LARGE asking for the 4th of 3 marks), or a formula that uses its own column. Wrap it in IFERROR(...,0) to show 0 instead.
  • "The formula is not valid": check the brackets ( ) and [ ], the commas, the quotes around text and the spelling of the function name.
  • A blank formula cell: no mark is entered yet in that student's row.
