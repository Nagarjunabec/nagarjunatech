Open Supabase > SQL Editor > New query. Paste a WHOLE file, press Run, wait for "Success".
Run one file at a time, in the order below. After each file you may see "Success. No rows returned" - that is normal.

CASE A - NEW or EMPTY project  (or you want to start again from zero; ALL DATA IS DELETED)
   Run ONE file:   00_ALL_IN_ONE_new_install.sql
   (v36: it is ONE single file with EVERYTHING: tables, functions, admin, notices / lab programs, lab batches and all marks features
    up to v30. Nothing else is needed. The numbered files 01 ... 16 below are only for updating an existing database.)

CASE B - project already running v12 / v13 / v14 / v15 / v16 with data you want to keep
   (already ran these before and only want the newest functions? Run just 02_functions.sql again.)
   1. 04_update_existing_database.sql
   2. 02_functions.sql
   3. 03_admin_seed.sql
   4. optional: 05_optional_passwords_to_regno.sql   (sets ALL student passwords back to the Reg No)

CASE C - already on v19 and you only want the new SYLLABUS + LESSON PLAN tabs (keeps all data)
   Run ONE file:   06_add_syllabus_lesson_plan.sql

CASE D - already running (v23 or older) and you want the new SEMESTER + MOBILE + PARENT MOBILE fields and profile photos (keeps all data)
   Run ONE file:   07_add_semester_mobile_photos.sql
   (Old students keep working; their semester / mobile / parent mobile are empty until you fill them with Edit.)

CASE E - already running v25 and you want v26 (rich notices, lab drop-downs, marks tables)  (keeps all data)
   Run, in this order:   1. 08_notice_labs_update.sql   2. 09_marks_tables.sql   3. 10_marks_formula_rules.sql

CASE F - already on v27 and you want v28 (row colors for Lab Marks)  (keeps all data)
   Run ONE file:   14_marks_row_colors.sql
   (If you are on an older version, first run the files of the cases above that you have not run yet, then 11, 12, 13 and 14.)

CASE G - already on v28 and you want v29 (description for every Lab Marks column)  (keeps all data)
   Run ONE file:   15_marks_column_description.sql

CASE H - already on v29 and you want v30 (Batch 1 / Batch 2 for Lab Programs; v31 has no further SQL)  (keeps all data)
   Run ONE file:   16_lab_batches.sql
   (Run it BEFORE you post a lab program with v30: the new site sends the batch to lab_add.)

CASE I - already on v30 / v35 and you want v36 (marks Publish button + Timetable)  (keeps all data)
   Run ONE file:   17_marks_publish_timetable.sql
   (Old Theory / Lab marks sheets stay visible to students. NEW sheets are hidden from students until you press Publish.)

CASE J - already on v36 and you want v37 (description in Edit marks + Colors legend, lab marks scroll from the right)  (keeps all data)
   Run ONE file:   18_marks_description_update.sql
   (Nothing is lost. If you are on an older version, run the files of the cases above first, then 17 and 18.)

v33 / v32 / v31: no new SQL. If you are already on v30, nothing has to be run.
